# ShifumiJS

Mini-jeu de Pierre-Feuille-Ciseaux (Shifumi) réalisé en HTML, JavaScript vanilla et Bootstrap.

> **Note :** Il s'agit d'un simple projet de découverte / prise en main de JavaScript (réalisé dans le cadre de mon cursus à l'IUT).  
> Pour un aperçu de projets plus représentatifs avec mise en place d'architecture et de CI/CD via GitHub Actions, voir : [anime-requester](https://github.com/Naexys/anime-requester).

---

## Fonctionnalités

- Choix du coup par le joueur (Pierre, Papier, Ciseaux)
- Choix aléatoire de l'adversaire (ordinateur)
- Suivi en temps réel des statistiques (victoires, défaites, égalités)
- Réinitialisation du compteur de score

## Technologies utilisées

- **HTML5**
- **JavaScript (Vanilla)**
- **Bootstrap 5** (CDN)
